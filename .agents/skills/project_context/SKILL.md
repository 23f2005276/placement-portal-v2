# Placement Portal Project Context

This skill provides key architectural context about the Placement Portal monorepo:

- **Frontend**: Vue 3 SPA built with Vite and Bootstrap 5.
- **Backend**: Python Flask API using Flask-RESTful, Flask-SQLAlchemy (SQLite database engine), and cookie-based JWT RBAC authentication.
- **Design Specifications**: Core API paths, database tables, and relationship mappings.

Refer to the primary project documentation at [Context.md](file:///Ubuntu/home/monish/Documents/IITM/ppa/Context.md) for full database schemas, endpoint definitions, and layout configurations.
